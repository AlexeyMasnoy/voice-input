# voice-input

Телеграм-бот, который принимает голосовые сообщения, превращает их в текст через Gemini и затем отправляет этот текст на обработку Gemini.

## Быстрый старт

1. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Настройте переменные окружения (пример в `.env.example`). Скопируйте пример и заполните значения:

```bash
cp .env.example .env
```

Файл `.env` будет загружен автоматически.

3. Запустите бота:

```bash
python main.py
```

## Меню

Используйте команду `/menu` или кнопки **Начать диалог** / **Записать запрос**, чтобы получить подсказку и перейти к отправке голосовых сообщений.

## Переменные окружения

- `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота.
- `GEMINI_API_KEY` — API-ключ Gemini (Google AI Studio).
- `GEMINI_MODEL` — модель Gemini для транскрипции и ответа (по умолчанию `gemini-2.0-flash`).
- `GEMINI_SYSTEM_PROMPT` — системный промпт для обработки текста.

## Примечания по Gemini API

- API-ключ можно получить в Google AI Studio: https://aistudio.google.com/
- Для запросов у аккаунта должен быть доступ к Gemini API и активные лимиты/биллинг при необходимости.
